# Northstar Poker

A mobile-first, installable play-money Texas Hold'em practice web app. The lobby is portrait-friendly; the table is optimised for landscape but remains playable in portrait.

## Run locally
Open `index.html` in a modern browser. For PWA install/offline support, serve the folder over HTTPS (for example with GitHub Pages or Netlify). A service worker won't register when opened as a `file://` URL.

## Included
- Responsive lobby with cash, Sit & Go and tournament-style table options
- Six-seat Texas Hold'em table, AI opponents, dealing, betting actions and hand evaluation
- Virtual-chip wallet with refill
- Local persistence for balance, hand history and practice stats
- Web app manifest and service worker

All chips are virtual. Northstar Poker is an independent practice app and is not affiliated with PokerStars or any real-money poker operator.
